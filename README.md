# GenWord
This game is powered by AI. Unlike regular word games with static lists, our AI generates a fresh, unique list of words live every time you start a match!

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
